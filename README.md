Personalized Fitness Coach using Flask and Angular

The AI agent accepts goal and workout preference(home or at the gym) from the user and generates a workout routine and nutrition. 
If the user has feedback on the recommendation they provide their preference in which the agent refines its response based on the feedback.

Key Component the agent exhibits include:

1. Goal initialization and planning - Which refers to breaking down user defined goals such as weightloss into actionable tasks or routines.
2. Reasoning using LLM - It uses gemini-pro api as a tool.
3. Learning and adaptation - since it integrates feedback mechanism for the purpose of refining its response it adapts to user preference inorder to narrow down the recommendation to fit the user.
